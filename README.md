# Asset Studio

Local-first web editor for preparing, editing and reviewing game assets. Initial use case: ZERO//DAY infrastructure graphics.

## Scope

Web browser only. Manual AI collaboration: import an image, prepare precise corrections, export files, and share them manually with ChatGPT. No API integration, backend, desktop packaging, authentication or remote image upload in V0.
